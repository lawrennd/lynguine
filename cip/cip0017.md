# CIP-0017: Cover remaining branches in config.context and config.interface

## Summary

`lynguine.config.context` and `lynguine.config.interface` sit under every flow load. Measured coverage on current `main` is **57%** (`context.py`) and **64%** (`interface.py`). Several of those gaps are real behaviour — credential expansion, logging defaults, inherit merge of `input`/`constants`, parent `output`/`series`/`parameters` rewriting, YAML error paths — not dead comments.

This CIP adds tests that call the production methods. It does not mock `_process_parent` or `_extract_mapping_columns` away. It does not change loader behaviour.

Addresses [REQ-0001](../requirements/req0001_code-quality-maintainability.md) (core-module coverage), [REQ-0002](../requirements/req0002_predictable-architecture.md) (explicit inherit/merge), and [REQ-0004](../requirements/req0004_secure-credentials.md) (credential references in context).

## Motivation

CIP-0001 raised `interface.py` from 56% to 61% and left `context.py` largely as two YAML-load tests. Later path-confinement work (CIP-000A / CIP-000D) added jail tests for `from_file` / `from_cwd_file`, but inherit merge, `_process_parent`, and credential expansion still sit behind uncovered branches.

Existing extended interface tests often patch the method under test (`_extract_mapping_columns`, `_process_parent`) and then assert the mock. That does not move coverage of the implementation. Codecov then flags the same files on unrelated PRs.

## Detailed Description

### Measured gaps (pytest-cov on `main`)

**`context.py` (49 missed / 113 statements)**

| Area | Why it matters |
|---|---|
| `_Config` dict protocol (`__setitem__`, `__delitem__`, `keys`, `get`, `update`, `__str__`, `__repr__`, …) | Context is used as a mapping; only `__getitem__` was exercised |
| `Context(data=...)` and empty-data `ValueError` | Constructor short-circuit vs file load |
| `machine.yml` merge | Local overlay on `defaults.yml` |
| Nested list expansion | `_expand_value` list branch |
| `${credential:key}` scalar, dict, missing, and unavailable | Secure credential interpolation |
| Logging defaults (missing `level`, missing `filename`, missing `logging`) | Silent defaults if YAML omits them |

**`interface.py` (181 missed / 505 statements)**

| Area | Why it matters |
|---|---|
| `_HConfig` parent get/set/del/`values`/`__str__`/`__repr__`/`__iter__` | Hierarchical mapping contract |
| `Interface(data=None)` / missing `directory` / missing `user_file` | Constructor validation |
| Inherit without `directory`; unbounded inherit; `inherit.writable` | Loader options |
| `__getitem__` `input` and `constants` hstack combinations | Child+parent merge |
| `inherit.append` of a scalar; `inherit.ignore`; missing key | Error paths |
| `_process_parent` rewriting parent `output` → `input`, `series` → `input`, `parameters` → `constants` | Pipeline inherit |
| `_extract_mapping_columns`, `_extract_fields` (non-list), `_extract_review_write_fields` | Field extraction |
| `from_file` / `from_cwd_file` / `_read_yaml_or_empty`: YAML error, `field=`, empty doc, missing file, `user_file=None` or a list | Loader edges |

### What we will not chase in this CIP

Two definitions are shadowed and cannot be covered without deleting them:

- `_HConfig.__iter__` at the first definition (uses `chain`, which `interface.py` does not import). The later generator `__iter__` wins.
- `Interface.default_config_file` returning `_linguine.yml` (typo). The later method returning `_lynguine.yml` wins.

`_process_parent` writes `self._parent._data["cosntants"]` when inherited constants already have a mapping. That is a typo (`constants`). A test that required the mapping-already-present branch would encode the crash. This CIP covers the working `else` branch and leaves the typo for a follow-up fix.

Import-guard lines in `context.py` (`except ImportError` when security extras are absent) need a module reload to execute. They stay out of scope.

Defensive `PathEscapeError` fallbacks after a name loop that already confined the same paths (for example `from_file` line 941) are not forced.

### Test placement

- Extend `lynguine/tests/test_config_context.py` for `_Config` / `Context`.
- Add `lynguine/tests/test_config_interface_coverage.py` for inherit merge, `_process_parent`, and loader edges. Keep the existing interface tests; do not rewrite the mocked ones.

Tests use `tmp_path` and real YAML files for inherit. Credential tests mock `get_credential_manager` only.

## Implementation Plan

1. Record baseline coverage on `main`.
2. Add context tests for dict protocol, file overlay, expansion, credentials, logging defaults.
3. Add interface tests that call production inherit/merge/loader code.
4. Re-measure; fill remaining reachable branches that the first pass missed.
5. Leave shadowed methods and the `cosntants` typo documented, not "fixed" as a side effect.

## Backward Compatibility

Tests only. No loader, inherit, or credential-expansion behaviour changes.

## Testing Strategy

```bash
poetry run pytest \
  lynguine/tests/test_config_context.py \
  lynguine/tests/test_config_interface.py \
  lynguine/tests/test_config_interface_extended.py \
  lynguine/tests/test_config_interface_coverage.py \
  lynguine/tests/test_access_paths.py \
  --cov=lynguine.config.context --cov=lynguine.config.interface \
  --cov-report=term-missing
```

Success is a clear lift from 57% / 64% on these two files, with new tests passing and no production edits.

**Result on this branch:** `context.py` **57% → 98%**, `interface.py` **64% → 98%**. Remaining misses are the import-guard, two shadowed methods, the `cosntants` typo, and defensive `PathEscapeError` fallbacks listed above.
